# AGENTS.md

Governance for AI coding agents (Codex, etc.) in this repo. The operator's `~/.claude/CLAUDE.md`
rules are the sole authority and are NEVER outranked.

- Approval = ONLY literal `GO` / `ГО`. "yes" / "approved" / "looks good" do NOT release a gate.
- Push = a separate `push` GO. Forced articulation + AI-risk stamp before state-changing actions.
- Windows `.ps1` = UTF-8-BOM + ASCII body; temp files on D:, never C:.

The Rosetta engineering workflow (Prepare -> Research -> Plan -> Act -> Validate) is available
ON-DEMAND, not always-on: see `.github/prompts/rosetta.prompt.md`. Specialist review routes to the
operator's agents (opt-in).
